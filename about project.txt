1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------

VoiceShield AI is a zero-trust, real-time audio deepfake detection and
mitigation platform built for the Indian telecom context. It listens to live
voice calls (via WebSocket streaming) or analyzes uploaded audio and decides in
real time whether the speaker is a real human (bonafide) or a synthetic /
deepfake voice (spoof / AI voice clone).

Target users  : telecom providers, banks, contact centers, parents
                ("Child Shield" mode)
Design goals  : free stack built on open / permissive licenses (attribution
                retained); SIH-hackathon-compliant data;
                DPDP Act 2023 privacy posture; sub-100 ms per-window latency.
Detection mix : ensemble of acoustic deep models + explainable prosodic
                features (jitter / shimmer / phase continuity) + cross-session
                speaker consistency + enterprise watermark check.

  score = 0.7 x model_prob + 0.3 x xai_risk

The project is a single git repository with one commit ("Initial commit").

2. HOW IT WORKS (PIPELINE)
--------------------------------------------------------------------------------

  Mic / call audio --> WebSocket --> Ring buffer (RAM only)
        |                                    |
        |                                    v
        |                         Acoustic models (ensemble)
        |                          - Dhwani (Wav2Vec2 XLS-R 300m + AASIST)
        |                          - AASIST-L official pretrained
        |                          - AASIST-L local retrained (fallback)
        |                          - XLSR-300m SIH cloud fine-tune
        |                                    |
        |                                    v
        |                         XAI prosody layer
        |                          jitter / shimmer / phase continuity /
        |                          pitch stability / noise-floor dropouts
        |                                    |
        |                                    v
        |                         Fusion + risk band --> verdict
        |                                    |
        v                                    v
  Scalar scores only            Alerts (Telegram / Gmail / ntfy.sh /
  (no raw audio leaves          Fast2SMS / webhook)  +  incident telemetry
  the device network)           --> I4C-ready forensic PDF
                                        |
                                        v
                            SHA-256 + Merkle root anchored to a local
                            proof-of-work (PoW) blockchain ledger
                            (optional Hyperledger-Fabric / IPFS external anchor)

Privacy: raw audio lives only in RAM and is overwritten every window.

8. LATENCY / PERFORMANCE BUDGET (per 3 s analysis window)
--------------------------------------------------------------------------------

  Stage                                Budget
  ------------------------------------ -------
  WebSocket ingest + ring buffer       <= 7 ms
  Prosodic feature extraction          <= 20 ms
  Model inference (INT8 CPU ONNX)      <= 35 ms
  Watermark + fusion + mitigation      <= 16 ms
  TOTAL                                <= 78 ms

  Windows: 3 s / 1 s hop default (300 ms / 100 ms fallback for legacy AASIST).
  Risk thresholds: adult >= 0.85 critical; child >= 0.70 critical.

12. QUICK START
--------------------------------------------------------------------------------

  Backend : cd backend
             python -m venv venv && venv\Scripts\activate
             pip install -r requirements.txt
             copy .env.example .env
             python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
             API docs -> http://localhost:8000/docs
  Frontend: cd frontend && npm install && npm run dev   (http://localhost:5173)
  One-click: double-click start_all.bat
  Cloud train classifiers (optional feature): upload cloud/colab_01..03
  notebooks to Colab and run (see cloud/README.md); drop the saved model into
  backend/models/<name>/ and point backend/app/config.py at it.

  REST API surface: /api/analyze, /api/detect, /api/sessions,
  /api/incidents (+ report/ack), /api/report/{call_id}, /api/blockchain,
  /api/blockchain/onchain, /api/speakers/register, /health, /info,
  and WS /ws/live/{call_id}.
